# Palette: warm

Warm earth tones on soft peach — cozy, inviting, natural.

## CSS Custom Properties

```css
:root {
    --bg-primary: #FFECD2;       /* Soft peach */
    --bg-secondary: #F5D6B8;     /* Warm sand */
    --text-primary: #3D2C2C;     /* Warm dark brown */
    --text-secondary: #8B6F6F;   /* Warm medium brown */
    --accent: #A0522D;           /* Sienna */
    --accent-soft: rgba(160,82,45,0.15);
    --zone-1: #ED8936;           /* Warm orange */
    --zone-2: #C05621;           /* Terracotta */
    --zone-3: #F6AD55;           /* Golden yellow */
    --zone-4: #D4A09A;           /* Rose */
    --border: #5D4037;           /* Brown */
    --line: #5D4037;             /* Brown */
    --shadow: rgba(93,64,55,0.1);
}
```

## Background

- **Primary**: `#FFECD2` soft peach, solid
- **Pattern**: Optional — subtle horizontal lines at 2% opacity

## Zone Color Usage

| Zone | Color | Hex | Best For |
|------|-------|-----|----------|
| `--zone-1` | Warm Orange | #ED8936 | Primary content, energy |
| `--zone-2` | Terracotta | #C05621 | Structural elements, borders |
| `--zone-3` | Golden Yellow | #F6AD55 | Highlights, positive data |
| `--zone-4` | Rose | #D4A09A | Soft accents, secondary info |

## Accent Rules

- `--accent` (#A0522D Sienna) for strong emphasis
- No cool colors — avoid blue, green, purple as primary elements
- Warm undertones throughout

## Best For

- Brand content
- Product showcases
- Lifestyle articles
- Food & drink topics
- Cozy, inviting tone
