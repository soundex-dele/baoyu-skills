# Palette: macaron

Soft pastel blocks on warm cream — educational, approachable, friendly.

## CSS Custom Properties

```css
:root {
    --bg-primary: #F5F0E8;       /* Warm cream */
    --bg-secondary: #EDE7DB;     /* Slightly darker cream */
    --text-primary: #1A1A1A;     /* Near black */
    --text-secondary: #7A7A7A;   /* Warm gray */
    --accent: #E8655A;           /* Coral red */
    --accent-soft: rgba(232,101,90,0.15);
    --zone-1: #A8D8EA;           /* Macaron blue */
    --zone-2: #D5C6E0;           /* Lavender */
    --zone-3: #B5E5CF;           /* Mint */
    --zone-4: #F8D5C4;           /* Peach */
    --border: #1A1A1A;           /* Near black */
    --line: #1A1A1A;             /* Near black */
    --shadow: rgba(0,0,0,0.08);
}
```

## Background

- **Primary**: `#F5F0E8` warm cream, solid or subtle noise texture
- **Pattern**: Optional — very faint dot grid at 3% opacity

## Zone Color Usage

| Zone | Color | Hex | Best For |
|------|-------|-----|----------|
| `--zone-1` | Macaron Blue | #A8D8EA | Primary info cards, first section |
| `--zone-2` | Lavender | #D5C6E0 | Secondary sections, supporting data |
| `--zone-3` | Mint | #B5E5CF | Positive outcomes, solutions |
| `--zone-4` | Peach | #F8D5C4 | Highlights, call-to-action areas |

## Accent Rules

- `--accent` (#E8655A Coral Red) for emphasis points only — sparingly
- Use for: key numbers, warning indicators, critical callouts
- Avoid: large background fills with accent

## Best For

- Educational content
- Knowledge articles
- Tutorials
- Concept explainers
- Warm, friendly tone
