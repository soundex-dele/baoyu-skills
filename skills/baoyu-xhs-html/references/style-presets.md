# Style Presets — Full Definitions

Quick-start combos mapping preset names to style + layout (+ optional palette).

## Knowledge & Learning

### `knowledge-card`
- **Style**: notion
- **Layout**: dense
- **Palette**: default (notion built-in)
- **Best for**: 干货知识卡、概念科普
- **HTML cues**: dot-grid background, thin-bordered cards, highlight text, clean grid layout

### `checklist`
- **Style**: notion
- **Layout**: list
- **Palette**: default
- **Best for**: 清单、排行榜
- **HTML cues**: numbered list with checkbox-style items, pill tags, clean lines

### `concept-map`
- **Style**: notion
- **Layout**: mindmap
- **Palette**: default
- **Best for**: 概念图、知识脉络
- **HTML cues**: central node with radiating branches, thin connection lines, zone-colored nodes

### `swot`
